About Me

Xin chào, tôi là Trần Hữu Hùng.

Tôi theo hướng Full-stack Developer , tập trung vào xây dựng ứng dụng web với React ở frontend và Java Spring Boot ở backend.

Trong các project của mình, tôi đã thực hành từ xây dựng giao diện và reusable components, thiết kế database, REST API, xử lý business logic đến authentication và authorization với Spring Security.

Tôi thích cách phát triển một chức năng theo luồng hoàn chỉnh: từ những gì người dùng nhìn thấy trên giao diện, dữ liệu cần lưu, API cần thiết cho đến cách backend xử lý nghiệp vụ.
